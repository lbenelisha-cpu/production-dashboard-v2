# IML Build 12.9.0 — Batch Quality Integrity

תיקון כרטיס המנה: לחיצה על מספר מנה מציגה כעת את כל תוצאות המעבדה כפי שהן בקובץ,
עם עמודת Inspection Lot, ועם החלטת השימוש האמיתית מקובץ ה-UD.

## התקנה
העתק `src/DashboardApp.jsx` אל תיקיית `src` של הפרויקט (דריסה), ובנה מחדש.
זהו הקובץ היחיד שהשתנה. `src/resourceEngine.js` לא נגע.

**חשוב:** התיקון בדדופליקציה חל על *העלאה*. רשומות שכבר נשמרו ב-Supabase
נשמרו אחרי שכבר איבדו שורות. יש להעלות מחדש את קובץ האיכות (או לנקות את
הטבלה ולטעון מאפס) כדי שהשורות החסרות יחזרו.

## מה תוקן

### 1. דדופליקציה שמחקה מדידות אמיתיות  (הבאג המרכזי)
`qualityRowKey` הרכיב מפתח ייחודיות בלי `Sample #` ובלי `Operation Activity`.
שתי דגימות נפרדות של אותו מאפיין שהחזירו במקרה את אותו ערך נחשבו לכפילות,
והשנייה נמחקה לצמיתות בשלב הקליטה.

במנה 0000002921 (מק"ט 50000000064) זה הוריד 50 שורות ל-36 — כולל **2 מתוך 7
הכשלים של FDN-277-3C4M**, כלומר חריגות אמיתיות נעלמו מהמסך.

השדות `Sample #`, `Operation Activity`, `Operation short text` ו-`Inspection Type`
לא נקראו כלל מהאקסל. עכשיו הם ממופים, והמפתח הוא
`Lot + Sample + Activity + Batch + Material + Characteristic + Date + Value + Status`.

אותה בעיה תוקנה ב-`addCharacteristic` (חתימת הכפילות בלוח החריגות).

### 2. הכרטיס הציג "טרם התקבלה החלטה" למרות שההחלטה קיימת
צ'יפ ה-QA קרא `QA Approval` / `Result Status` מקובץ *האיכות* ושרשר אותם בפסיקים,
כך שמנה עם תוצאות מעורבות הציגה `"Acceptance, Rejection"`. קובץ החלטות השימוש
לא הגיע לשם בכלל.

עכשיו הצ'יפ מציג `UD Code · QA Status` מההחלטה האחרונה בקובץ ה-UD.
למנה 0000002921 → **A7-For Internal Use · מנה פסולה**.

### 3. הכרטיס ערבב Inspection Lot תוך-תהליכי עם סופי
ב-SAP רק Lot שמתחיל ב-4 מקבל החלטת שימוש; Lot שמתחיל ב-3 הוא בדיקה
תוך-תהליכית. הכרטיס חיבר את שניהם ל-KPI אחד, כך ש"8 חריגים / 81%" תיאר משהו
שאף אחד לא מחליט עליו.

נוסף:
- עמודות **Inspection Lot / סוג בדיקה / Sample # / שלב** בטבלת האיכות
- מסנן סופי / תוך-תהליכי (מופיע רק כשיש יותר מ-Lot אחד)
- פס ורדיקט מתחת ל-KPI שמפריד בין הבדיקה הסופית לתוך-תהליכיות

### 4. מוני KPI
- `goodCount` חושב כשארית (`סה"כ - חריגים`), כך ששורה בלי סטטוס נספרה כתקינה.
  עכשיו נספרת במפורש, ושורות ללא סטטוס מוצגות בנפרד ולא נכנסות לאחוז ההצלחה.
- "חריגות פתוחות" הציג את מספר כל שורות ה-UD. עכשיו סופר רק כאלה בלי UD Code.
- לשונית "חריגים" מציגה את מספר הפתוחות.
- `Approved characteristics` ו-`Inspection Lot UD Date` לא נקראו מהקובץ — נוספו.

### 5. קוד דיבאג שחנק את הטעינה
- `console.log` על **כל שורת איכות** — 263,000 קריאות בכל חישוב מחדש של האינדקס
- `alert()` חוסם על מנה `0000000101`
- שלושה `console.log` נוספים בבניית הכרטיס, אחד מהם מדפיס את כל מערך האיכות

זה ההסבר הסביר ביותר לכך שהאפליקציה נתקעה בטעינת קובץ האיכות. הכל הוסר.

### 6. מנה על כמה מק"טים
`batchMaterialKey` מחזיר מחרוזת ריקה אם המק"ט חסר, ואז הכרטיס יצא ריק לגמרי.
נוסף fallback לפי מספר מנה בלבד, עם הודעה בכרטיס שמסבירה שמוצגים כל המק"טים.
(`byBatch` היה מוגדר ומוחזר אך מעולם לא אוכלס — עכשיו הוא בשימוש.)
